## Состав группы

## Идея компании

Кофейня "Мама, я устала" в строящемся ЖК "Символ" с датой открытия в 2027 году, одновременно со сдачей домов в ЖК. Продаём вкусный кофе жителям жилого комплекса и домов поблизости и создаем комфортное рабочее место для фрилансеров
